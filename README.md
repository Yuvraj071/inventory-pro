# InventoryPro — Inventory Management UI (Static HTML)

A responsive student-project front end inspired by Practical 29. Built with HTML, Bootstrap 5 and custom CSS only.

## Pages
- `index.html` — Dashboard
- `products.html` — Product list, search/filter UI
- `product-form.html` — Add product form
- `categories.html` / `category-form.html` — Categories
- `suppliers.html` / `supplier-form.html` — Suppliers
- `report.html` — Stock summary report
- `login.html` — Demo login screen
- `assets/css/style.css` — Custom styling

## Important limitation
This is a static front-end demonstration. It has sample data only; login, CRUD, search/filter, and saving forms are not connected to a server/database. It is not a Laravel/database-driven implementation and should not be represented as having real authentication or persistent CRUD. Static HTML can be published using GitHub Pages.

## Publish on GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a public repository named `inventory-management`.
3. Upload all files and folders in this project (keep `index.html` at the repository root).
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Wait for GitHub Pages to publish. Your URL will be shown on that Pages screen, usually `https://YOUR-USERNAME.github.io/inventory-management/`.
7. Copy that actual URL into your practical PDF only after opening and testing it.

## Update later
Edit the files, commit changes in GitHub (or push from Git), and GitHub Pages will publish the update. A GitHub Pages site URL and repository URL are different links.

Do not put passwords, secrets, or private information in this repository.
